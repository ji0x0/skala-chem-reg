## 판정 규칙에 반영한 원문 표현

- "○% **이상**" (REACH XVII, 산안법 별표 12, 화관법 고시) → `≥` / SVHC 제33조 "**above** 0.1%" → `>`
- 화관법 **제한물질**은 특정 용도만 금지 → 기준 이상이어도 "확인 필요 — 제한 용도에 해당하는지"
- **조건부** 등재(니켈 불용성 화합물만, 6가크롬 화합물만, 석면 1% 이상 탈크만 등) → "확인 필요"
- 조건을 정리하지 않은 REACH XVII 항목(부록 포함 1,900여 행) → "확인 필요 — 용도·농도 조건 원문 확인"
- CLP 조화된 분류 → 판매 금지가 아니라 "함유 혼합물의 분류·표시·SDS에 반영할 정보"

## 남은 한계

- "○○ 및 그 화합물"처럼 총칭으로 지정된 항목은 CAS로 모든 화합물을 대조할 수 없다 (대표 화합물만 명시: 산화아연, 삼산화안티몬)
- 변경 수집(미국 관보·국내 법제처 고시·EU 개정 법령)은 브리핑에만 쓰고 규제 DB에 자동 반영하지 않는다 — 판정은 확인일 기준 목록으로 한다 (DB 갱신은 Step 12: 감지 → 담당자 승인 후 반영)
- 공식 목록은 개정된다. 확인일 이후 개정은 `import_official_lists.py`로 다시 가져오고 이 문서를 갱신한다

## 확인 방법 메모

- ECHA·EUR-Lex 웹사이트는 자동 요청을 막는다(403·봇 확인). EUR-Lex 문서는 같은 내용을 Cellar API(`publications.europa.eu/resource/celex/…`, `Accept: application/xhtml+xml`)로 받았다
- ECHA 이용약관 팝업은 수락하지 않고 표 내용만 읽었다
- 국가법령정보센터 별표 뷰어는 글자 위치 XML을 제공한다 → 위치로 줄을 재구성해 항목·CAS·특별관리물질 표시를 추출 (줄바꿈으로 끊긴 CAS 2건은 원문 확인 후 수기 보정)
- 국내 고시의 별표가 "첨부파일 참조"인 경우 첨부 목록(`admRulAttFlList.do`)에서 xlsx를 찾았다
