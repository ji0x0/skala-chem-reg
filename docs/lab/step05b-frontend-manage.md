# Step 5b — Vue 화면: 제품 관리·규제 목록

> **이후 변경**: 규제 목록은 Day1 저녁 공식 원본 대조 후 **11종**(등재 데이터가 없는 규제는 목록에서 제외)이 됐다.

## 목표
담당자가 화면에서 제품 배합(CAS·함량·역할)을 추가·수정하고 저장 즉시 규제 판정을 보며(R54), 규제 목록과 등재 물질을 찾아볼 수 있게 한다(R55).
Step 4의 제품·규제 API를 그대로 쓴다. 백엔드 수정 없음.

```
[질의응답·브리핑] [제품 관리] [규제 목록]          ← App.vue 탭 (KeepAlive로 상태 유지)
                    │              │
                    │              └ 물질 검색 → 함유 제품 클릭 ─┐
                    └──────────── provide('openProduct') ◀───────┘
```

## 설계 포인트
- **검증은 두 번**: 화면 검사(`cas.js`)는 저장 전에 틀린 행을 바로 보여 주는 편의 기능. 최종 판단은 서버(`validate_product`) — 브라우저 검사는 우회될 수 있다
- **저장 = 검증 → 저장 → 판정**: 서버가 `{product, judgement}`를 돌려주므로 화면은 저장 직후 판정을 그대로 띄운다. 서버는 `refresh_catalog()`로 에이전트 제품 목록도 갱신
- **"없음"과 "모름"을 구분**: 등재 데이터가 없는 규제는 "등재 데이터 없음 — 판정에서 빠지므로 해당 없음으로 오해하지 마세요"로 표시. 데이터 상태 `to_verify`는 모든 화면에서 "원본 확인 전" 배지
- **적용 제외도 보여 준다**: "왜 이 규제는 안 나왔지?" → 판정표의 "적용 제외 n건 보기"(예: EU 미수출)
- **미량 성분 강조**: 배합표에서 불순물·잔류 단량체 역할은 주황색 (판정에 영향)

3) 제품 목록·상세: 12개 제품과 판정 요약(P001 exceeds 4 · listed 3 …). P001을 누르면 배합 9개 성분과 판정표

4) 제품 추가 — 일부러 틀리게
- **+ 새 제품** → 제품명 `수성 방청 코팅제`, 수출 KR·EU
- 성분 1: `7732-18-5` Water 주용제 69.8 / 성분 2: `71-43-3` Benzene 불순물(제조 공정) 0.2
- **저장하고 판정** → 2번 행이 빨갛게 "CAS 형식 또는 체크 디지트 오류", 합계 70 빨간색, "함량 합계 70 wt% — 100 ± 0.5 wt%여야 함" (서버 요청 없이 화면에서 차단)

5) 고쳐서 저장
- CAS `71-43-2`, Water `99.8` → 저장
- "P013 추가 완료" + 판정: **exceeds** EU 부속서 XVII Entry 5 · 벤젠 0.2% / 0.1% (불순물이어도 함량 기준 초과)
- 질의응답 탭에서 "P013 규제 문제 있어?" → 같은 판정으로 답변 (에이전트가 새 제품을 바로 인식)

6) 수정: P013 **수정** → 벤젠 `0.05`, Water `99.95` → 저장 → exceeds가 사라지고 XVII는 below, 목록 배지도 바로 갱신

7) 규제 목록 탭
- 지역별 13개 규제, 등재 수·확인 전 수. 국내 허가·금지·제한물질과 미국 SNUR은 "등재 데이터 없음"
- 등재 물질 표의 CAS를 누르면 그 물질 검색
- `벤젠` 검색 → 벤젠·에틸벤젠(부분 일치), 등재 규제 6건, 함유 제품 P004·P012·P013 → **P012** 누르면 제품 관리 탭에서 P012가 열림

> 확인 중 만든 P013은 `data/app.db`에 남는다 (gitignore). 초기 상태로 돌리려면 서버를 끄고 `data/app.db`를 지운 뒤 다시 실행 → CSV로 다시 채워짐.

## 실제로 겪은 문제
- **마우스로만 누를 수 있는 링크** → `href` 없는 `<a @click>`·`<li @click>`은 키보드 포커스·화면 낭독기에 잡히지 않음 → `<button>` / `tabindex` · `role` · Enter 처리 / 근거 번호는 `href="#"` + `aria-label`
- **수정 폼에서 원본 복사 실패 가능성** → props는 반응형 Proxy라 `structuredClone`이 오류 → JSON 복사로 (취소하면 원본 그대로)
- **좁은 화면에서 CAS가 두 줄로 끊김** → CAS·기준값 열은 줄바꿈 금지
- 자세한 내용: [troubleshooting.md](../../troubleshooting.md)
