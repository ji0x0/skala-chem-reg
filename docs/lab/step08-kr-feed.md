# Step 8 — 국내 변경 수집 (ReAct 에이전트 + 안전장치)

> **이후 변경**: 아래 흐름 끝의 '승인'은 Step 9에서 제거했다 — 영향 제품이 있어도 바로 답한다.

## 목표
"국내외 규제 원문을 **수집**"한다는 서비스 설명을 사실로 만든다. 지금까지 국내는 등재 목록 대조만 했고, 변경 수집은 미국 연방 관보뿐이었다.
법제처 국가법령정보 Open API로 최근 개정된 고시를 찾고, **개정 내용**에 회사 제품 성분이 있으면 영향 분석·근거·브리핑까지 미국 문서와 같은 흐름에 태운다.
국내 수집 에이전트는 **ReAct**(LLM이 검색어를 정해 도구를 직접 반복 호출)로 만들되, 판정과 "무엇이 바뀌었나"는 코드가 정한다.

```
gate ──Send──▶ 국내 수집 에이전트 (kr_feed)
                 ② 안전장치(코드): 물질 지정 고시는 항상 검색 (사고대비물질·제한·금지·허가물질·관리대상 …)
                 ① ReAct(LLM):    검색어를 정해 search_kr_admin_rules를 2~4번 호출 → 관련 고시 선택
                                  (도구가 실제로 돌려준 일련번호만 인정, 실패하면 ②로 대신)
                 ③ 확인(코드):    get_kr_admin_rule → "이번 개정 내용"에 회사 물질? → 영향 분석 / 아니면 참고
review: 90일에 없으면 1년으로 넓혀 재검색 ──▶ summarize(번역 없음) → impact(국내 판정) → write → guard → 승인
```

## 설계 포인트
- **"무엇이 바뀌었나"는 개정 내용으로만**: 고시는 개정될 때마다 전문이 다시 실린다. 「유해화학물질별 구체적인 취급기준」처럼 물질 목록 전체가 든 고시는 현행 본문에 회사 물질이 27종이나 있다. 본문 전체로 판단하면 "바뀌지 않은 내용"을 변경으로 보고한다 → 개정문 + 이번 발령번호의 부칙 + 신구 조문 대비(`admrulOldAndNew`)에서 바뀐 조문만 본다. 셋 다 없으면 "개정 내용 미제공 — 원문 확인"
- **고유번호**: 국내 고시는 물질을 CAS 대신 화관법 고유번호(예: 97-1-309)로 가리킨다 → 화관법 목록으로 CAS 변환
- **ReAct + 안전장치**: LLM에게 검색 전략을 맡기면 넓게 찾지만 빠뜨리거나 실패할 수 있다. 물질 지정 고시는 코드가 항상 찾고, LLM이 고른 번호는 도구가 실제로 돌려준 것만 인정한다
- **Dynamic Planning**: 국내 고시는 개정이 드물다 → 90일에 없으면 1년으로 (미국은 7일 → 30일)
- **질문의 지역 우선**: "국내" 질문에 LLM 계획이 미국까지 넣으면 다른 문서·제품이 섞인다 → 질문에 지역이 있으면 코드가 바로잡는다

## 결과 (실제 API, Ollama qwen3:8b)
- ReAct: 모델이 검색어 3개(유해화학물질·사고대비물질·제한물질)를 정해 도구 호출 → 90일엔 없음 → 1년 재검색에서 「사고대비물질의 지정」(화학물질안전원고시 제2026-2호, 2026-03-10) 선택
- 부칙 경과조치의 "자일렌(CAS No. 1330-20-7 …)" → 크실렌 함유 **P004(15%)·P012(25%)** → 국내 판정 근거와 함께 승인 대기
- 2026-09-18 「화학물질의 분류 및 표시 등에 관한 규정」 개정(물질 명칭 변경·38종 신설)은 개정 내용에 회사 물질이 없어 영향 없음 (고유번호로 확인)

## 실제로 겪은 문제
- **본문 전체로 판단하면 과장** — 취급기준 고시에 회사 물질 26종이 걸림 → 개정 내용과 현행 본문 언급을 분리
- **한글명 "N-(1,3-디메틸부틸…)"을 괄호 제거해 "N-"로 잘라 83번 오탐** → 끝의 괄호 별칭만 떼고, 한글이 없는 조각은 버림
- **기본 검색 결과가 확인 한도를 채워 핵심 고시가 밀림** → 안전장치는 물질 지정 고시로 좁히고 최신순
- **ReAct 안 도구 호출이 화면에 안 보임** — 노드 안 작은 그래프에서 `get_stream_writer()`가 안쪽 통로를 잡음 → 바깥 통로를 넘김
- **Docker에서 국내 수집이 "키 미설정"** — MCP 서버(자식 프로세스)에 환경변수가 전달되지 않음. 로컬은 서버가 `.env`를 직접 읽어 가려져 있었고, 제품 DB 경로도 같은 이유로 빠져 있었음 → 백엔드 설정을 명시적으로 전달
- **"국내" 질문에 미국 문서·제품이 섞이고, 모델이 근거 없는 연결을 씀** → 질문의 지역이 LLM 계획보다 우선
- 남은 한계: 소형 모델이 부칙 경과조치("~한 것으로 본다")의 날짜를 "제출 기한"으로 잘못 요약한 사례 — 날짜 자체는 원문에 있어 가드가 잡지 못함 (요약 규칙 추가, 사람 검토 대상)
- 자세한 내용: [troubleshooting.md](../../troubleshooting.md)
