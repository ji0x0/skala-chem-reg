# Step 10 — 정기 브리핑 탭

## 목표
담당자가 매주 질문하지 않아도 **지난주(월~일) 국내외 규제 변경**이 주차별로 정리돼 있게 한다. 새 경로를 만들지 않고, 같은 브리핑 그래프에 **고정 기간**만 넣는다.
담당자는 읽고 **"검토 완료"**로 표시한다 (승인이 아니라 검토 기록 — 설계 9절).

```
매주 월요일 09:00 (스케줄러)  또는  scripts/run_weekly.py
  → "2026-10-12~2026-10-18 국내외 화학물질 규제 변경 브리핑" + period
  → 이해: 국내외 변경 브리핑으로 확정 → 수집: 미국 관보·법제처를 그 기간으로만 (넓히지 않음)
  → 요약·판정·작성·검사 → 주차별 저장 (검토 대기)
  → 「정기 브리핑」 탭: 주차 목록 → 본문·근거 → [검토 완료]
```

## 만드는 파일

| 파일 | 역할 |
| --- | --- |
| `mcp_servers/reg_feed_server.py` (수정) | 미국·국내 검색에 `since`·`until` (스냅샷에서도 날짜로 거름) |
| `app/agents/*` (수정) | `period` 입력: 수집 작업에 기간 전달, 재검색 확대 없음, 변경이 없으면 "이번 주 확인 결과: … 없습니다" |
| `app/repositories/weekly_db.py` | 주차별 저장(ISO 주차), 검토 완료, 예시 시드 |
| `app/weekly.py` | 주차 계산, 실행(`run_weekly`), 매주 월요일 스케줄러 (`WEEKLY_SCHEDULE=true`일 때만, Docker 기본 켬) |
| `app/api/weekly.py` | 목록·상세·검토 완료, 생성(관리자 토큰) |
| `frontend/src/views/WeeklyView.vue`, `App.vue`, `client.js` | 「정기 브리핑」 탭 |
| `scripts/run_weekly.py`, `data/weekly/*.json` | 지난 주차 생성·내보내기 → 처음 실행 때 예시로 채움 |
| `tests/test_weekly.py` | 주차 계산, 기간 검색, 생성·검토·API, 시드·스케줄러 |

## 설계 포인트
- **같은 그래프, 다른 입력**: 정기 브리핑 전용 코드를 만들지 않는다 — 기간만 고정. 검사·근거·범위 판정이 그대로 적용된다
- **"변경 없음"도 답이다**: 기간을 고정했으니 넓혀 다시 찾지 않는다. 회사 관련 변경이 없으면 그 사실을 첫 문장으로, 관련 없는 변경은 참고로
- **자동 생성은 Docker에서만**: 개발·테스트 중에 LLM이 저절로 돌지 않게 기본은 끔
- **생성은 관리자만**: LLM을 여러 번 부르는 무거운 작업

## 따라 하기

```bash
uv run pytest -q tests/test_weekly.py
```

지난 3주 다시 만들기 (실제 관보·법제처·Ollama):

```bash
uv run python scripts/run_weekly.py --backfill 3 --export data/weekly
```

화면: 「정기 브리핑」 탭 → 주차 선택 → 근거 확인 → [검토 완료]

## 실제로 겪은 문제
- **"국내외"의 "국내"만 잡혀 국내만 검색** → "국내외"는 특정 지역이 아니므로 지역 판별에서 제외, 정기 브리핑은 수집 가능한 모든 지역
- **질문 속 날짜 "2026-10-12"의 "1"이 물질로 잡혀 TCE 문서가 "요청 범위 밖"으로** — 규제 데이터의 영문명이 "1", "2."로 잘린 행 26개(화관법 금지물질 쉼표 잘림, REACH 부속서 XVII 부록의 번호 칸). 가져오기 스크립트 수정 후 재생성(확인일 유지 `--verified-on`), 빌드 검증 규칙 8(영문명에 글자), 매칭에서 글자 없는 이름 제외
