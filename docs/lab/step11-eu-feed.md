# Step 11 — EU 수집 에이전트

## 목표
"EU REACH의 가장 최근 변경은?"에 "확인할 수 없음"(Step 9)이 아니라 **실제 개정 법령**으로 답한다.
EUR-Lex 웹사이트는 자동 요청을 막지만(403), 같은 공식 문서를 EU 출판국 **Cellar**가 SPARQL(검색)·XHTML(본문)로 준다. 키가 필요 없다.

```
search_eu_acts  : SPARQL — REACH(32006R1907)·CLP(32008R1272)를 "개정한(amends)" 법령, 채택일 기간, 영문 제목
get_eu_act      : Cellar 본문 → 회사 물질(영문명·CAS) 언급, 채택일("of 8 August 2025"), 관보 게재일("L series 2025/1731 11.8.2025")
EU 수집 에이전트: 회사 물질이 나오는 법령 → 영향 분석 / 나머지 → "회사 제품 성분과 관련 없는 변경"(참고)
                  90일에 없으면 1년 재검색 · SVHC 추가는 법령이 아니라 ECHA 결정 → "확인하지 못한 항목" + DB 기준 최근 등재
```

## 만드는 파일

| 파일 | 역할 |
| --- | --- |
| `mcp_servers/reg_feed_server.py` (수정) | `search_eu_acts`(기간·최근 N일, 스냅샷), `get_eu_act`(본문·날짜·물질) |
| `scripts/fetch_eu_snapshot.py`, `data/feeds/eu_*` | EU 스냅샷 (최근 400일 개정 법령 3건과 본문) |
| `app/agents/subagents.py` (수정) | `_eu_feed` — 미국 수집과 같은 방식(코드가 순서를 정함) |
| `app/agents/graph.py`, `understand.py` (수정) | EU 작업·1년 재검색·찾지 못함 안내, EU 변경 + SVHC 언급이면 DB 기준 최근 등재도 |
| `app/domain/coverage.py`, `responses.py` (수정) | 수집 가능 지역에 EU (중국·일본만 "수집 미지원") |
| `app/domain/mentions.py` (수정) | 정식 이름이 더 큰 물질명의 조각이면 인정하지 않음 (`bis[phenol]` ≠ 페놀) |
| `tests/test_eu_feed.py` | 검색 기간, 날짜·언급, 이름 경계, 브리핑, 요청 물질 없음 |

## 설계 포인트
- **"amends" 관계로 찾는다**: 키워드 검색이 아니라 법령 간 공식 관계(개정)로 — 다른 법령의 언급에 섞이지 않는다
- **관련 없는 개정도 참고로 보인다**: "가장 최근 변경"을 물으면 회사 물질과 무관해도 최근 개정 목록은 답이다 (영향 분석에서만 빠짐)
- **할 수 없는 것을 밝힌다**: SVHC 후보 목록 추가는 ECHA 결정 → 수집에 안 보인다는 사실을 "확인하지 못한 항목"에, 대신 규제 DB(확인일 기준)의 최근 등재를 함께
- 정기 브리핑에도 EU가 들어간다 (지난 3주 예시 다시 생성)

## 실제로 겪은 문제
- **"Phenol"이 `…bis[phenol] (1:1)`에서 잡힘** — EU 법령은 긴 화학 명명법을 그대로 싣는다. 단어 경계(글자·숫자)만 보면 대괄호·하이픈 안 조각도 이름으로 인정 → 정식 이름은 앞뒤가 `[ ] - , '`이면 인정하지 않음 (괄호 약어 "(TCE)"는 그대로)
- **본문만 받으면 채택일·게재일이 비어 있음** — 게재일은 줄바꿈 때문에 정규식이 안 맞음, 채택일은 검색 결과에만 있음 → 본문 첫머리에서 둘 다 읽음
- **정기 브리핑 예시 3건 모두 품질 경고** — 가드가 코드가 넣은 고시 번호·기간·"10월 18일"을 지어낸 숫자로 판정. Step 10에서 커밋한 예시에도 있었는데 놓쳤음 → 가드 기준 자료(`_guard_reference`)에 문서 표기·기간(한국어 표기 포함)·질문 추가, 직접 시험하는 테스트(수정 전 실패 확인), 예시 재생성
- **모델이 한 출처의 "관련 없는 변경"을 모든 출처에 쓰고, 확인하지 않은 중국·일본을 "변경 없음"으로** → 출처별 상태를 코드가 알려 줌
- **국내 ReAct가 "신의료기술 평가" 고시를 고름** → LLM이 고른 고시도 제목에 화학 관련 단어가 있어야 참고로 싣는다
- 자세한 내용: [troubleshooting.md](../../troubleshooting.md)
