# 최종 주제 — 국내외 화학물질 규제 브리핑·영향 분석 에이전트

> 국내외 화학물질 규제 변화를 수집해 **한국어로 브리핑**하고, **우리 제품 원료(CAS)와 대조해 영향과 대응 기한**을 알려 주며, 고객 안내문 초안까지 만드는 멀티에이전트 서비스.

- 결정일: 2026-10-20 (선정 과정: [1차](topic-selection.md) → [2차](topic-domain.md) → 최종)
- 과제 유형: 2번 신규 프로젝트. Base Agent의 "수집 → 병렬 조사 → 분석 → 작성 → 검증 → 승인" 그래프 구조를 재사용
- ⚠️ 법률 자문이 아니다. 모든 판정에 원문 링크와 기준일을 붙이고, 최종 판단은 담당자가 한다. 회사·제품·원료 목록은 가상 데이터, 규제 원문은 공개 자료다.

## 1. 다루는 규제 (산업용 화학물질)

| 구분 | 규제·목록 | 판정 내용 | 데이터 출처 | 언어 | 우선 |

| 국내 | **화학물질관리법** — 유독·허가·제한·금지물질 | 해당 시 취급 허가·제한·금지 | 국립환경과학원 고시 목록 (공식 원본 확인 필요) | 한국어 | 1 |
| 국내 | **산업안전보건법** — 관리대상유해물질, 특별관리물질, 허가대상, 제조금지 | 작업장 관리·MSDS 의무 | 시행규칙 별표, 안전보건공단 MSDS API(규제현황 항목 확인 필요) | 한국어 | 1 |

| EU | **REACH SVHC 후보 목록** | 제품(성형품) 내 0.1 wt% 초과 시 정보 제공 의무 | ECHA 후보 목록 253종(2026-02 기준). 재사용 조건 확인 필요 | 영어 | 1 |
| EU | **REACH 부속서 XVII 제한** | 특정 용도·농도 제한 | ECHA 제한 목록 | 영어 | 2 |
| EU | **CLP 유해성 분류** (조화된 분류) | 표시·포장 의무, 혼합물 분류 기준 | CLP 부속서 VI | 영어 | 2 |
| 중국 | **우선관리 화학물질 목록** | 해당 시 관리 강화 대상 | 생태환경부 공고 (3차 23종, 2025-12-25) | 중국어 | 3 |
| 일본 | **화학물질심사규제법(화심법, CSCL)** | 지정 물질 제조·수입 제한·신고 | 경제산업성 등 공개 목록 | 일본어 | 3 |

- 우선 1: Day1 구현 / 우선 2: Day1 후반~Day2 / 우선 3: Day2 (번역 기능 시연용 — 중국어·일본어 원문)
- 목록 전체를 다 넣지 않는다. **가상 제품 원료와 관련된 물질 + 대표 물질 위주로 출처·기준일을 붙여 정리**한 규제 DB로 시작한다. 정리한 범위를 README와 발표에 명시한다.

| 항목 | 내용 |
| --- | --- |
| 업무 | 국내외 규제 변경을 모니터링하고, 자사 제품이 영향받는지 판단해 영업·생산에 알림. 고객의 "SVHC 함유 여부 확인서" 요청에 대응 |

| 목표 | 오늘 안에 "영향 있는 규제 / 영향받는 제품 / 할 일과 기한"을 팀에 공유 |
| 쓰는 화면 | 사용자 프론트엔드 (주간 브리핑, 제품 영향표, 질의응답, 안내문 승인) |

## 4. 서비스 구성

```
Vue 화면 ──(REST + SSE, CORS)──▶ FastAPI
                                 │ lifespan: LLM · MCP 연결 · 체크포인터 · 그래프 1회 생성
                                 ▼
             LangGraph Supervisor (LangChain 모델·프롬프트·구조화 출력)
  route ─┬─ 단순 질의 (물질·규제 조회) ─────────────────────────────▶ 답변
         └─ 브리핑·영향 분석
             plan ▶ gate ═Send═▶ [국내 수집 | 해외 수집 | 규제 DB 대조] (병렬)
                  ▶ review(누락·재조회) ▶ 번역·요약 ▶ 영향 분석(코드) ▶ 대응 작성
                  ▶ guard(숫자·CAS·날짜·근거 검사) ▶ validate(LLM-as-Judge)
                  ▶ approval(안내문 승인, interrupt) ▶ finalize
                                 │
   MCP 서버 (직접 제작): reg-feed (연방 관보·법제처 API 래핑) / reg-db (규제 목록 DB 조회, 용어집 RAG)
                        / product (가상 제품·원료 목록)
   외부 MCP 서버: 공개 서버 1개 연결 검토 (예: 한국 법령 MCP, PubChem MCP)
                                 │
            SQLite(체크포인터·규제 DB) · 벡터 저장소 · LangSmith(관리자 대시보드)
```

## 7. 계획 대비 실제 (2026-10-21)
